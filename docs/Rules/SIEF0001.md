# SIEF0001 - AsNoTracking() should be first in the chain

## Explanation

When using `AsNoTracking()` in Entity Framework queries, it is a best practice to call it immediately after accessing the `DbSet` and before any other query methods. This improves code visibility and makes it clear at a glance that the query is not tracking entities.

## Code example

````csharp
using var ctx = new TestContext();

// Compliant - AsNoTracking is first in the chain
ctx.Entities.AsNoTracking().Where(x => x.Id == 1).ToList();

// Compliant - AsNoTracking is directly on DbSet
ctx.Entities.AsNoTracking().ToList();

// Non-Compliant - AsNoTracking is called after Where
ctx.Entities.Where(x => x.Id == 1).AsNoTracking().ToList();

// Non-Compliant - AsNoTracking is called after multiple methods
ctx.Entities.Where(x => x.Id == 1).OrderBy(x => x.Name).AsNoTracking().ToList();
````

## Configuration

This analyzer is always enabled and does not have configuration options.
